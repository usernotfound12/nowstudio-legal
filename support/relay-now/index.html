What it does

Relay Now lives in the menu bar. Paste or type a link, pick a browser from the list, and it opens there — with the tracking parameters (utm_source, gclid, fbclid and dozens more) stripped out first. It is for the moment you want this one link in Chrome, or in a private-feeling browser, without changing your system default.

Where's the window?

There isn't one, and there is no Dock icon by design — the menu bar item is the whole app. Click the arrow icon in the menu bar to open the panel. If you can't see it, the menu bar may be full: quit an app or two, or widen the bar by hiding another menu extra.

Opening links from other apps

Use Set as Default Browser… in the panel and macOS will ask you to confirm. After that, a link clicked in Mail, Slack or anywhere else opens the Relay Now panel with the link already filled in, waiting for you to choose a browser. You can undo this any time in System Settings › Desktop & Dock › Default web browser. Relay Now works fine without it — pasting a link by hand is the primary way to use it.

A browser is missing from the list

Relay Now looks for a fixed set of well-known browsers — Safari, Chrome (including beta and Canary), Firefox and Developer Edition, Edge, Brave, Opera and Opera GX, Vivaldi, Arc, DuckDuckGo — and shows only the ones actually installed on this Mac. If you have just installed one, reopen the panel to refresh. If your browser isn't on that list at all, tell us which one and we will look at adding it.

A link opened in the wrong place, or not at all

Relay Now hands the link to the browser app you picked and reports back if macOS refuses. If a link won't open, check the browser still exists where it was installed. A link reopened from history needs the browser it originally used to still be installed — the panel will say so if it isn't.

A site broke after cleaning

Removing tracking parameters is safe for almost every site, but if a link only works with its full query string, paste it straight into your browser instead. Send us the link and we will check whether a parameter should be left alone.

Clearing your history

Relay Now remembers the last 50 links it opened and lists the most recent eight under Recent, all of it stored on this Mac only. Each row has an ✕ to delete that one entry, and a circular arrow to open it again in the same browser. Clear, beside the Recent heading, erases the whole history at once. Deleting the app removes it too.
