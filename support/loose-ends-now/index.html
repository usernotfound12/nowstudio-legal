Getting started

Create a follow-up with a person, a remembered detail and the next action. Request a reminder if you want one and allow notifications in macOS Settings. Complete or reopen follow-ups from their detail view. Export a complete backup before moving Macs or removing app data. This support page covers the sandboxed Mac App Store edition.

Get help

Email info@nowstudioai.com with the app name, app version, operating system and steps that caused the problem. Please remove private details from attachments.
